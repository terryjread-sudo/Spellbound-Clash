# Spellbound Clash - Tower Defense & Reading Game

A fully contained, browser-based tower defense game designed for an 8-year-old. It seamlessly embeds reading challenges into the core game loop for summoning units and upgrading towers.

## Features
- **Tug-of-war Gameplay:** Build wizards to defend, summon knights to attack!
- **Wizard Health & Upgrades:** Wizards don't die, they retreat to heal. Spend gold to upgrade them to get Swift Boots or even an Ultimate Teleport!
- **Hidden Reading:** Click the "Read for Gold" button to spawn a word challenge (synonyms, antonyms, rhyming). Correct answers yield gold to spend!
- **Level Editing:** Toggle Edit mode to click the map and add new spots for wizard towers.

## Deployment to GitHub Pages
1. Create a new repository on your GitHub account.
2. Extract the contents of this zip file (`index.html`, `style.css`, `game.js`, `README.md`) and upload them to the root of your repository.
3. In your repository settings, go to **Pages**.
4. Select the `main` (or `master`) branch as the source and click Save.
5. In a few minutes, your game will be live at `https://<your-username>.github.io/<repo-name>/`!
